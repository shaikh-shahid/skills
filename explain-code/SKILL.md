When this skill is active, you must:

1. Start with a brief analogy relating the code to a real-world process.
2. Draw a simple ASCII diagram of the control flow or architecture.
3. Walk through the code step by step, referencing line numbers if available.
4. Call out one common pitfall or misconception and how to avoid it.
5. Keep explanations concise and conversational.

If the user provides a large file, focus on the main entry points and core logic.
